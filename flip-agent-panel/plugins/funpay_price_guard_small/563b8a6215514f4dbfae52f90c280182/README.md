# FunPay Price Guard Small

Плагин проверяет цену предмета на площадке FunPay: разрешает выдачу только когда подтверждено (confirmed=True), все три цены (price, min_price, max_price) конечны и min_price <= price <= max_price. Иначе скоринг отклоняется с краткой причиной. Без сети, без зависимостей от Telegram/Cardinal.

## Goal

Создай маленький плагин funpay_price_guard_small без сети. score(item) безопасно читает price, min_price, max_price и confirmed. allowed=true и score=100 только когда confirmed is True, все три цены конечные числа и min_price <= price <= max_price. Иначе allowed=false и score=0 с краткой причиной. async handle(event, ctx) возвращает score(event). В tests/test_plugin.py все вызовы async handle обязательно выполняй через asyncio.run(...). Добавь тесты NaN, строки, пустой dict, границы и строгий confirmed.
