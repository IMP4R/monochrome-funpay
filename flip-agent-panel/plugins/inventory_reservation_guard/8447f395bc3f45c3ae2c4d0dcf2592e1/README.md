# Inventory Reservation Guard

Validates inventory reservation items: checks SKU is a non-empty string, quantity is an integer between 1 and 100 (excluding booleans), available is an integer >= quantity, and confirmed is strictly true. Returns allowed=true and score=100 only when all conditions are met; otherwise allowed=false and score=0. No exceptions are raised on malformed input.
