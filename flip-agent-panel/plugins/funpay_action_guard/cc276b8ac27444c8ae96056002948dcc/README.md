# FunPay Action Guard

Плагин оценивает действия FunPay (create_lot, update_lot, delete_lot, send_message) и разрешает их только при подтверждённом флаге. Не выполняет сетевых запросов, не бросает исключения на некорректных данных.

## Goal

Создай небольшой плагин funpay_action_guard. Он не делает сетевых запросов. score(item) принимает dict с action, confirmed и price. Для action create_lot, update_lot, delete_lot или send_message возвращает score 100 и allowed true только если confirmed строго true; иначе score 0 и allowed false. Для неизвестного action всегда allowed false. handle(event, ctx) возвращает тот же результат. Не бросает исключения на некорректных данных.

Generated by the agent pipeline and activated only after sandboxed unit tests pass.
