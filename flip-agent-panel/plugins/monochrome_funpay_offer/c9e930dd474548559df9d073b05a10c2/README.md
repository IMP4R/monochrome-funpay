# Monochrome FunPay Offer

Pure adapter plugin that validates monochrome gift data and prepares/publishes FunPay offers without network or file dependencies.

## Goal

Создай серверный плагин строго со slug monochrome_funpay_offer. Это чистый адаптер без сети и файлов: хост отдельно получает подарок и изображения из Monochrome Panel и отдельно публикует на FunPay. Plugin.score(item) проверяет словарь подарка: непустые collection, model, backdrop, market, item_id, listing_text, generated_image_url; sale_price должен быть конечным числом от 1 до 10000000, bool запрещён; confirmed должен быть строго True только для публикации. Для action=prepare_offer confirmed не требуется, для action=publish_offer без confirmed=True возвращай allowed false. async handle(event,ctx) для prepare_offer возвращает безопасный draft: node_id 3064 (Telegram / Подарки), funpay_type из входа или Прочее, fields[type2]=Продажа, русское название до 100 символов с моделью, фоном и ценой, description_ru из listing_text, description_en пустое, price целым числом, active false, deactivate_after_sale true, source с market/item_id, preview_image_url. Для publish_offer возвращает тот же draft только при строгом confirmed=True. Не выполняй HTTP и не храни секреты. Любой неправильный ввод должен возвращать allowed false и errors, без исключений. Напиши не меньше 12 unittest-тестов, включая None, bool как цена, NaN, infinity, границы, неизвестный action, async через asyncio.run, prepare без подтверждения, publish без и с подтверждением, ограничение заголовка.

Generated by the agent pipeline and activated only after sandboxed tests pass.
