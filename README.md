# Монохромные подарки → FunPay

Интеграция анализа Telegram-подарков и FunPay с управляющей веб-панелью.

## Состав

- `PUBLICATION.md`
- `flip-agent-panel`/
- `monochrome`/

## Подготовка и запуск

Манифесты зависимостей в этой копии:
- [monochrome/requirements.txt](monochrome/requirements.txt)

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.

## Ограничения снимка

- Исходный снимок с сервера. Только код, интерфейс, небольшая документация и тесты без captured fixtures. Оригиналы и серверные сервисы не изменены. Секреты, cookies, базы, Telegram-сессии, логи, склад и пользовательские данные исключены. Runtime, публикация лотов и оплаты не проверялись. Две части: flip-agent-panel и monochrome. Нужны собственные .env, Telegram API/сессии, MONOCHROME_ADMIN_TOKEN, FunPay credentials и внешние зависимости. FunPayAPI и крупные vendor JS не включены: установите их отдельно. Модели, изображения, каталоги и сгенерированные карточки не включены. Это исходники интеграции, не готовый production deploy.
- При оформлении репозитория приложение не развёртывалось, платежи и внешние API не запускались; тесты не перепроверялись.
